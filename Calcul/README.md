# Calcul

Un petit jeu de calcul mental : des additions à la suite, contre la montre, avec un pavé numérique à l'écran (pensé pour l'iPad).

**Jouer :** [atelier-lionel.github.io/Games/Calcul/](https://atelier-lionel.github.io/Games/Calcul/)

## Dans le jeu

- Choisir les additions : une ou plusieurs tables d'addition, ou toutes les additions dont le résultat ne dépasse pas un nombre donné.
- Choisir le nombre d'opérations et le temps maximum ; le chrono décompte pendant la partie.
- Points : +1 par bonne réponse, −1 par erreur, +3 si tout est fini dans le temps.
- Bruitages et petite musique fabriqués par le navigateur, qu'on peut couper dans les réglages.
- Les réglages sont gardés dans le navigateur de l'appareil ; rien n'est envoyé ailleurs.

## Fichiers

- `index.html` : le jeu entier (une seule page, sans bibliothèque externe ni fichier audio).
