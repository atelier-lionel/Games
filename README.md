# Games

Les jeux web de l'atelier : de petites applications à ouvrir dans un navigateur, sur Mac ou sur iPad, sans rien installer.

## Les jeux

| Jeu | Pour quoi faire | Jouer |
|---|---|---|
| **Filou lit** | Apprendre à lire (CP), avec Filou le chat : sons, syllabes, mots et petites phrases | [atelier-lionel.github.io/Games/Filou/](https://atelier-lionel.github.io/Games/Filou/) |

## Comment jouer

- Ouvrir l'adresse du jeu dans **Safari**.
- Sur iPad : bouton Partager › **Sur l'écran d'accueil** pour avoir une icône comme une app.
- Sur Mac : menu Fichier › **Ajouter au Dock**.
- La progression est enregistrée dans le navigateur de chaque appareil ; rien n'est envoyé ailleurs.

## Organisation du dépôt

- Un dossier par jeu, avec son propre README.
- Ce dépôt ne contient que les fichiers nécessaires pour jouer ; le développement (tests, manuels, versions) se fait ailleurs.
- Les pages sont publiées automatiquement par GitHub Pages à chaque mise à jour.
