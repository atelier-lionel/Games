# Robot

Un petit jeu de programmation : un robot se déplace case par case sur un damier, piloté par des commandes tapées au clavier ou par les flèches. Il faut ramasser les pièces (`take`), répéter des gestes avec les boucles (`repeat`), éviter les murs et passer les portes, en utilisant le moins d'instructions et de pas possible.

**Jouer :** [atelier-lionel.github.io/Games/Robot/](https://atelier-lionel.github.io/Games/Robot/)

## Dans le jeu

- Un menu pour régler la taille des cases, le nombre de colonnes, de lignes et de pièces, la difficulté des murs, la couleur et le personnage (robot, chat ou fusée).
- Les réglages sont gardés dans le navigateur de l'appareil ; rien n'est envoyé ailleurs.
